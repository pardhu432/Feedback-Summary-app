# Customer Feedback Summary  (DataSpark Challenge #84)

A beginner-friendly, menu-driven Python app that records customer ratings, validates input,
stores data locally (JSON), and generates executive summaries with frequently mentioned
feedback themes, trends and warnings.

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt                          # optional (matplotlib for chart)
python main.py                                           # needs Python 3.10+
python -m unittest discover tests                        # run the tests
```
Tip: choose **9) Load sample dataset** to load 40 realistic rows (4 deliberately invalid rows
are rejected and logged to `exports/import_errors.log`).

## Features
| Requirement | Where |
|---|---|
| Menu-driven terminal UI (ANSI colour, pagination) | `feedback_summary/ui.py` |
| Defensive validation (date, name, category, rating 1-5, comment length) | `validation.py` |
| Analytics: averages, distribution, category stats, keyword mining, monthly trend, sentiment | `analytics.py` |
| JSON persistence, atomic writes, corrupt-file recovery (auto-backup) | `storage.py` |
| Search by keyword / category / rating range | menu 3, `Store.search` |
| Executive summary | menu 4, `reports.summary_lines` |
| Export Markdown / text audit log / CSV / PNG chart | menu 7, `reports.py` |
| Threshold warnings (low averages, sharp drops, runs of 1-star) | menu 5, `analytics.warnings` |
| Bulk CSV import with row-by-row error log | menu 8, `Store.import_csv` |

## Demo script (5 min)
1. `python main.py` -> show the banner.  2. **9** load sample data.  3. **1** add an entry and type
bad values (date `2026-99-99`, rating `abc`, rating `7`) to show validation.  4. **4** summary
+ **5** warnings.  5. **3** search "late" / category Delivery.  6. **0** exit, relaunch -> data persists.
7. **7** export -> open `exports/summary.md` and `summary_chart.png`.
